What this converter gets right

lists

A list gets its own file

An order with three items does not become items/0/sku, items/1/sku, items/2/sku. The items land in their own CSV with the order's ID on every row, so they join back with a lookup.

numbers

Long IDs are written digit for digit

A 19-digit order number is written exactly as it was. A spreadsheet app can still round it when it opens a CSV, so the converter names the columns at risk before you download, and Excel output is one click away.

safe to open

Opens cleanly in Excel

A text cell that starts with =, +, - or @ gets a leading apostrophe, so it cannot run as a formula. Files are UTF-8 with the marker Excel looks for, so Müller stays Müller.

one CSV per list .zip download saved setups

Same files every month

You see real rows from your own file first, and rename headings or drop columns. Save the setup, and next month's file gives you the same files with the same headings.

From the command line

The same converter runs offline with Node. draft writes a setup you can read and edit; convert writes one CSV per table.

npx jsonloupe draft orders.json -o spec.json
npx jsonloupe convert orders.json --spec spec.json --to csv

The file never leaves your browser

The conversion runs inside this tab. There is no server to send your file to, so it keeps working with your wifi off. A file you are not allowed to email is a file you are allowed to convert.
