What this editor does differently

edit

Tree and text, side by side

Change a value in the tree, or type in the code view with search and folding. Select a value in the tree and the code view jumps to its line. Undo and redo cover every edit.

repair

Broken JSON gets fixed

Trailing commas, single quotes, Python True and None, and log extracts cut off half way are repaired. The repair is flagged, and the original text is kept.

numbers

Long IDs keep every digit

A 19-digit order number or a long decimal price stays exactly as you typed it. Nothing is turned into a rounded number on the way in or on the way out.

Big files stay fast

The tree draws only the rows on screen, and the heavy work runs in the background, so a file with millions of items opens and scrolls without freezing the tab. Files up to 200 MB open.

Find anything

Search by text or by pattern, filter the tree down to the matches, and copy the path of any value with one click.

Why nothing is uploaded

The editor runs inside this browser tab. Your file is read here and nowhere else. There is no server to send your file to, which is why it keeps working with your wifi off. Nothing is logged, counted, or kept anywhere but your own computer.
