The three things that make most JSON diffs noisy

lists

List items are matched by id

Items are paired by their id, by a key you choose, or by a key found for you. A list in a new order shows no changes, and a changed item shows only its changed fields.

noise

Ignore the fields that always change

Timestamps and request IDs differ on every run. Ignore them by name or by path, and only the real changes are left.

numbers

Long IDs are compared exactly

Two IDs that differ only in the last digit are different. A diff that rounds both to the same number tells you they are equal.

Changes by path

Every change is listed with its exact path, for example $.orders[3].total. Click a change to see it in the tree, next to the values around it.

changed  $.orders[3].total     41.90 → 44.90
added    $.orders[7]
removed  $.customer.fax

Large files too

The comparison runs in the background, away from the page you are looking at, so two large files can be compared without freezing the tab.

Why nothing is uploaded

The comparison runs inside this browser tab. Both files are read here and nowhere else. There is no server to send your file to, which is why it keeps working with your wifi off. Nothing is logged, counted, or kept anywhere but your own computer.
