Why big files open here

speed

Only the visible rows are drawn

The tree draws what is on screen and nothing else, and a big list opens in pages of 10,000 items. Reading, searching and filtering run in the background.

formats

Compressed files open directly

Open .json, .jsonl and Zstandard .zst files, or paste Base64-Zstd text. They are decoded in your browser, not on a server.

numbers

Long IDs keep every digit

IDs longer than 15 digits can be rounded by other viewers. Here they stay exactly as they are in the file.

Find the heavy part

Each closed branch shows its size in bytes, so the part that makes the file big is easy to find. Search by text or pattern, and filter the tree to the matches.

Ask questions without code

Count, group and filter with short queries that run in this tab, for example the failed tasks grouped by reason.

$.tasks[?(@.status == 'FAILED')] | group(@.reason)

Why nothing is uploaded

The viewer runs inside this browser tab. Your file is read here and nowhere else. There is no server to send your file to, which is why it keeps working with your wifi off. Nothing is logged, counted, or kept anywhere but your own computer.
