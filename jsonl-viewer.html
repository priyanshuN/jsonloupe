What happens to your JSONL

records

Each line becomes one record

The file opens as one list with one item per line, also when the format is called NDJSON. The file size beside the document's name says JSONL.

speed

Big logs stay responsive

The tree draws only the rows on screen, and a long list opens in pages of 10,000 records. Reading, searching and filtering run in the background.

numbers

Long IDs keep every digit

Trace IDs and order numbers longer than 15 digits can be rounded by other viewers. Here they stay exactly as they are in the file.

Search every record at once

Search by text or pattern across all records, and filter the tree down to the matches. Each closed record shows its size in bytes, so the heavy ones are easy to find.

Count and group records

Short queries run in this tab, for example the errors in a log grouped by service.

$[?(@.level == 'error')] | group(@.service)

Why nothing is uploaded

The viewer runs inside this browser tab. Your file is read here and nowhere else. There is no server to send your file to, which is why it keeps working with your wifi off. Nothing is logged, counted, or kept anywhere but your own computer.
